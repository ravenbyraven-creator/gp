Profile + Match Log v1.14 — Spec for Replit

Why

Two gaps from the v1.13 review:





Clicking a wrestler does nothing. In gp/artifacts/universe-mode/src/components/Roster.tsx every card is wrapped in CardMenu, which is only a right-click ContextMenu plus a hover-revealed three-dot dropdown. There is no left-click handler and no Wrestler Profile page to navigate to.



No match results exist anywhere. The only "match" data is the free-text result: string inside ShowMatch on an AI-generated ShowCard (see gp/lib/api-client-react/src/generated/api.schemas.ts line ~390). The AI can't read W/L records because they don't exist; the user can't see "Cody is 2-1 vs Gunther" without scrolling through every storyline.

This build solves both at once: Wrestler Profile is the home for the W/L data, so we ship one coherent screen instead of two disconnected features.

Legacy (championship reigns) is kept as-is. We read useTitleReigns() from inside the Wrestler Profile but we do not modify the Legacy tab.

1. Data model (NEW)

Create gp/artifacts/universe-mode/src/lib/matches.ts:

import type { UniverseDate } from "./calendar";

export type MatchOutcome =
  | "PIN" | "SUBMISSION" | "DQ" | "COUNTOUT"
  | "NO_CONTEST" | "DRAW" | "KO" | "OTHER";

export interface MatchSide {
  id: string;                  // crypto.randomUUID()
  wrestlerIds: string[];       // 1 = singles; 2+ = tag/trios
  label?: string;              // optional team name override
}

export interface MatchResult {
  id: string;
  date: UniverseDate;

  // Where it happened
  showId?: string;             // raw | smackdown | custom show id
  showName?: string;           // denormalized so deleting a show doesn't orphan
  eventName?: string;          // PPV / event name override
  slot?: string;               // OPENER, MID, MAIN_EVENT (denormalized from ShowCard)

  // Linkage back to source data
  historyEntryId?: string;     // the ShowCard RivalryEntry this came from, if any
  rivalryId?: string;          // optional manual tag

  // The match itself
  sides: MatchSide[];          // 2 sides for normal; 3+ for multi-way
  winnerSideId?: string;       // undefined if NO_CONTEST/DRAW
  outcome: MatchOutcome;
  finish?: string;             // "Cross Rhodes", "Powerbomb thru table"
  stipulation?: string;        // "Hell in a Cell", "Last Man Standing"

  // Title context
  titleId?: string;            // championship at stake
  titleChanged?: boolean;      // if true, surface a hint to also log it in Legacy

  // Polish
  stars?: number;              // 0..5 step 0.25
  notes?: string;
}

Add the storage hook + derivations in the same file:

export function useMatchResults() {
  return useLocalStorage<MatchResult[]>("umc.matchResults", []);
}

export interface WrestlerRecord {
  wins: number;
  losses: number;
  draws: number;       // includes NO_CONTEST + DRAW
  total: number;
  winPct: number;      // 0..1
  currentStreak: { kind: "W" | "L" | "N"; length: number };
  titleMatchWins: number;
  titleMatchLosses: number;
}

export function deriveWrestlerStats(
  wrestlerId: string,
  matches: MatchResult[],
): WrestlerRecord;

export function deriveHeadToHead(
  sideAIds: string[],
  sideBIds: string[],
  matches: MatchResult[],
): { aWins: number; bWins: number; draws: number; lastMatchId?: string };

export function wrestlerMatches(
  wrestlerId: string,
  matches: MatchResult[],
): MatchResult[];                  // sorted by date desc

Stats rules (be explicit so Replit doesn't guess):





A wrestler "wins" a match when their MatchSide.id === winnerSideId.



outcome === "DRAW" || outcome === "NO_CONTEST" counts as a draw for everyone in the match.



outcome === "DQ" || outcome === "COUNTOUT" still has a winner (the side that didn't get DQ'd / counted out) and a loser.



Streak resets on a draw.



Title match = titleId !== undefined.

Add unit tests in src/lib/matches.test.ts covering: singles W/L, tag W/L (both members credited), multi-way (only winner side gets W, all others get L), draws, DQ wins, streak calculation, head-to-head with overlapping rosters.
