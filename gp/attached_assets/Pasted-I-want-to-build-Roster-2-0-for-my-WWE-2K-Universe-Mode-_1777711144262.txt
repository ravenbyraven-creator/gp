Feature goal:
Turn the Roster tab into a Universe control room with 3 main areas:
1. Wrestlers
2. Championships
3. Stables / Tag Teams

Roster Tab Structure:
- Add a clean section/tab/filter inside the Roster page for Wrestlers, Championships, and Stables.
- Keep the existing wrestler roster behavior working.
- Do not remove existing roster data or break existing localStorage data.
- Use the existing app design language: dark WWE-style creative board, kayfabe tone, polished cards, not spreadsheet UI.

Championships Requirements:
- Users can add, edit, and delete championships.
- A championship should support:
  - title name
  - brand
  - division/type: world, women’s, midcard, tag, specialty, custom
  - current champion or champions
  - title belt image/photo
  - active/inactive status
  - optional notes/current direction
- Users can change the champion manually.
- Users can change/upload/edit the title photo.
- Championships should appear in AI context so chat, show generation, rivalry suggestions, news, and creative desk understand who the champions are.
- If a champion is involved in a rivalry, generated ideas should understand the title stakes.
- Empty states should explain that championships help the AI understand stakes.

Stables / Tag Teams Requirements:
- Users can add, edit, and delete stables/tag teams.
- A stable/tag team should support:
  - stable/team name
  - members
  - leader
  - manager
  - brand
  - alignment: face, heel, tweener
  - status: active, teasing breakup, broken up, reunited, inactive
  - stable logo/photo
  - optional notes/current direction
- Users can upload/change/remove a stable logo/photo.
- If no stable logo/photo exists, display the stable as member names, for example:
  - “Randy Orton & Batista”
  - “Roman Reigns, Solo Sikoa & Jimmy Uso”
- The stable/team name can still be custom, but the fallback display should use the member names when no logo or custom name is available.
- Stable data should appear in AI context so chat, show generation, rivalry suggestions, news, and creative desk understand alliances, managers, tag teams, factions, and possible betrayals.
- AI should be able to reference stables naturally, but should not invent stable history that is not saved in the app.
- Empty states should explain that stables help the AI understand alliances and faction drama.
