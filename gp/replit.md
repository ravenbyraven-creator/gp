# Workspace

## Overview

pnpm workspace monorepo using TypeScript. Each package manages its own dependencies.

**Gorilla Position** — a mobile-first companion web app for WWE 2K26 Universe Mode. Tracks roster, shows, rivalries, and a universe clock; uses an AI booker (OpenAI via Replit AI Integrations proxy) for storylines, full show cards, surprise moments, promos, conversational chat, and rivalry chapter/memory analysis. Universe-mode app stores all user data in localStorage (no DB). See `VISION.md` and `UNIVERSE_MODE_ASSISTANT.md` for product spec.

## Artifacts

- `artifacts/api-server` — Express 5 API at `/api`, AI booker routes in `src/routes/booker.ts` (gpt-5.4 via `@workspace/integrations-openai-ai-server`). Includes `POST /booker/issue` (weekly magazine: cover + 4-6 features) and `POST /booker/rumor` (single dirt-sheet item) for the NEWS tab.
- `artifacts/universe-mode` — React + Vite frontend (`@workspace/universe-mode`), the Gorilla Position app. Uses `@assets/*` alias to `attached_assets/` for brand images (gorilla logo, RAW/SmackDown art, WWE logo).
- `artifacts/mockup-sandbox` — design canvas iframe sandbox.

### NEWS tab — WWE.com 2003 scratch-logo aesthetic

The first tab in the universe-mode app. Manual triggers ("Print Weekly Issue" + "Spill A Rumor") plus an auto-trigger that runs the moment `UniverseClock.handleAdvance` crosses into a new calendar week — provided night-notes were logged for the week being recapped and no issue exists for it yet. Auto-generated issues are dated to the prior week, get the next sequential number, and appear with the unread red dot on the NEWS tab + a "NEW ISSUE(S) ON THE STAND" notification strip with DISMISS (marks all issues read). Persists `umc.issues` and `umc.rumors` arrays in localStorage. Inside an open issue, "FILE COVER STORY" opens a `mode="issue-cover"` `FileToRivalryDialog` that builds a `kind:"magazine"` `RivalryEntry` (stable id `magazine-<issueId>`) and inserts it into `umc.history` before linking — pre-selecting any active rivalry that matches the AI's `IssueCoverData.suggestedRivalryHint`. Magazine entries surface in the Rivalries tab (new MAGAZINES filter pill) and feed back into the AI as `recentMagazineHeadlines` (last 3) on every booker endpoint. The newsstand page uses a WWE.com 2003-2004 dark steel-and-red palette (near-black bg, brushed-metal header strip, hero panel with full-bleed wrestler photo, headlines sidebar, story panels row, back-issues strip). MagazineCover/IssueView/RumorView retain the Russo-era WWF Magazine aesthetic for inside-the-issue viewing — two complementary aesthetics, one tab. Static SVG assets in `artifacts/universe-mode/public/news/` (`scratch-logo.svg`, `scratch-accent-divider.svg`, `brushed-metal.svg`, plus legacy `halftone.svg`, `grain.svg`, `paper.svg`).

## Stack

- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 24
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **API framework**: Express 5
- **Database**: PostgreSQL + Drizzle ORM
- **Validation**: Zod (`zod/v4`), `drizzle-zod`
- **API codegen**: Orval (from OpenAPI spec)
- **Build**: esbuild (CJS bundle)

## Key Commands

- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- `pnpm --filter @workspace/api-server run dev` — run API server locally

See the `pnpm-workspace` skill for workspace structure, TypeScript setup, and package details.
